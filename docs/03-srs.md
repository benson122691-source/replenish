版本：0.1（2026-11-08）｜追溯：FR 對應 PRD 的 US/AC，並對應 06-test-plan 的 TC。

## 2. 邊界規則

- BR-1 品項或門市不存在：API 回 404，訊息包含無效欄位。
- BR-2 預測值不得為負，輸出前截斷為 0。
- BR-3 建議補貨量為整數；庫存已足夠時為 0。
- BR-4 服務水準限制 0.5 ≤ SL ≤ 0.999；交期 1–28 天；庫存 ≥ 0；MOQ ≥ 0。
- BR-5 沒有價格的日期（品項尚未上架）不納入訓練與評估。
